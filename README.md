# Sentinel Studio 145 – Compact Memory Skill\n\nThis repository provides a self-contained **Compact Memory** skill for Claude Code, along with a FastAPI backend and a React UI for interactive use.\n\n## Overview\nThe skill converts prose notes into a compact symbolic notation, improving memory efficiency and readability. Each fact is represented as `<TYPE>:<VALUE>` with four types: `note`, `rule`, `obs`, `task`.\n\n## Files\n- `skills/compact-memory/SKILL.md` – Skill definition and notation.\n- `skills/compact-memory/compact_memory.py` – Python implementation.\n- `app.py` – FastAPI service exposing `/skill` endpoint.\n- `index.html` – React UI for interactive skill invocation.\n- `requirements.txt` – Dependencies.\n- `test_compact_memory.py` – Unit tests.\n- `feature-plan.json` – Feature tracking.\n- `PLAN.md` – Project plan.\n- `STATUS.md` – Development status.\n\n## Installation\n\n1. Clone the repository.\n2. Install Python dependencies:\n   ```bash\n   pip install -r requirements.txt\n   ```\n3. Start the FastAPI server:\n   ```bash\n   uvicorn app:app --host 0.0.0.0 --port 8000\n   ```\n4. Open the UI in a browser:\n   - If you have a static server, place `index.html` at the web root and open `http://localhost:8000/index.html`.\n   - Or run a simple server like `python -m http.server 8000` from the repository root and navigate to the index page.\n\n## Usage\n\n- **Via UI**: Use the web interface to input prose notes and view the compressed output.\n- **Programmatically**: Send a POST request to `/skill` with JSON:\n  ```json\n  {\n    \"skill\": \"compact-memory\",\n    \"input\": \"Your prose notes here...\"\n  }\n  ```\n  The response includes the compact output.\n\n## Testing\n\nRun the unit tests:\n```bash\npython -m pytest test_compact_memory.py -v\n```\n\n## Development\n\n- The skill implementation is deliberately simple; you can extend `skills/compact-memory/compact_memory.py` with more sophisticated heuristics.\n- To add new skills, follow the pattern of `SKILL.md` and create a Python function that is imported into `app.py`.\n\n## License\nApache-2.0\n
